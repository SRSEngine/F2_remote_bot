# RemoteShot: اسکرین‌شات از ریموت با مختصات آماده‌ی کد

ابزاری شبیه Win+Shift+S که ناحیه‌ای از صفحه‌ی ریموت xbrp را می‌گیرد، اسمش را می‌پرسد،
عکس را در پوشه‌ی `Shots` ذخیره می‌کند و یک خط آماده‌ی پیست در کلیپ‌بورد می‌گذارد:

```
("Cancel", 320,200,320,180)
```

## استفاده
1. `RemoteShot.exe` را اجرا کنید. یک آیکون کنار ساعت ویندوز می‌آید.
2. کلید **Ctrl+Alt+S** را بزنید یا روی آیکون کلیک کنید.
3. ناحیه را با موس بکشید. Esc یا کلیک راست لغو می‌کند.
4. اسم را بنویسید و Enter بزنید.

کلیک راست روی آیکون: «باز کردن پوشه Shots» و «خروج».
Win+Shift+S مال خود ویندوز است و برنامه‌ی دیگر نمی‌تواند آن را بگیرد. برای همین Ctrl+Alt+S انتخاب شد.

## مختصات
- عددها نسبت به **تصویر ریموت** هستند، در فضای فریم 1280x720 (همان فضای Founder و Play.py).
  اندازه‌ی پنجره‌ی ریموت (۹۶۰، ۱۲۸۰، تمام‌صفحه) و مانیتوری که روی آن است اثری ندارد.
- پنجره‌ی ریموت با کلاس پنجره‌ی `XBRPVideo` پیدا می‌شود. ریموتی انتخاب می‌شود که وسط ناحیه روی آن است، پس با چند ریموت هم درست کار می‌کند.
  تصویر ریموت کل ناحیه‌ی داخلی پنجره را پر می‌کند (بدون نوار سیاه)، پس تبدیل یک نسبت ساده است.
- عکس ذخیره‌شده از **فریم واقعی ریموت** است (دستور `snap` روی pipe همان ریموت که از `Controller\remotes\*.json` پیدا می‌شود)،
  نه از مانیتور. پس اندازه‌اش با استریم یکی است و به‌عنوان تصویر نمونه‌ی `scr.find` قابل استفاده است.
  اگر pipe جواب ندهد، عکس از مانیتور برداشته می‌شود و در پنجره‌ی اسم نوشته می‌شود.
- اگر ناحیه بیرون از ریموت باشد، مختصات نسبت به مانیتور است و هشدار داده می‌شود.
- اسم تکراری فایل قبلی را پاک نمی‌کند: ` (2)` به آخر اسم اضافه می‌شود. اسم خالی = تاریخ و ساعت.

## نکته
`scr.find("Name", ...)` تصویرها را از `Founder\Templates` می‌خواند، ولی RemoteShot در `Screenshot\Shots` ذخیره می‌کند.
برای find، عکس را به `Founder\Templates` کپی کنید (یا `ShotsDir` را در کد عوض کنید).

## ساختن دوباره
کد: `src\RemoteShot.cs` (C#، WinForms، بدون نصب چیزی). کامپایلر .NET Framework خود ویندوز:

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -nologo -target:winexe -codepage:65001 -optimize -out:RemoteShot.exe -r:System.Windows.Forms.dll -r:System.Drawing.dll src\RemoteShot.cs
```
قبل از ساختن، RemoteShot در حال اجرا را از منوی آیکون ببندید.
